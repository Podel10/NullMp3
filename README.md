# Null MP3

A **local, offline-first music player** for Android and Windows. Your files stay on the device — no account, no streaming lock-in.

## Why people use it

- Play music from **Download**, **Music**, Telegram folders, or any folder you add
- Library tabs: songs, albums, artists, playlists, folders + search
- Mini player and full now-playing with queue, shuffle, repeat, favorites
- **Video and GIF covers** (first frame in the list, motion on now playing)
- Online lyrics and cover search when you want them; **offline mode** when you don’t
- 5-band equalizer, sleep timer, playback speed, music editor / cut
- Beat waves around the cover (optional)
- Tools: **SoundCloud** download by link or song name → saved to Download; video → GIF for covers
- Many UI languages

## Platforms

- Android (phones / tablets)
- Windows

## Privacy

Null MP3 is a local player. It does not upload your music. Optional online features (lyrics, covers, SoundCloud) only run when you use them and offline mode is off.

## Build

```bash
flutter pub get
flutter run
```

Release APK:

```bash
flutter build apk --release
```

Output:

`build/app/outputs/flutter-apk/app-release.apk`
